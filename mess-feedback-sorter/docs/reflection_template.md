# 400-word reflection (write this yourself)

The reflection must be in your own words. Prompts to get you started (delete this list when done):

1. What did the LLM get wrong in your live run, and which Python layer caught it?
2. Which part of the code could you explain line by line, and which part still feels shaky?
3. Where did you use AI to help, and where did you override it?
4. Why must the warden still read the original comments, even with the safety net?
5. What would you test next with 50 real comments?

(Target: about 400 words.)
